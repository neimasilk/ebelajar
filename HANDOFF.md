## Cara Update Section (teknis)

### Method: DOMParser + Fetch (paling reliable)
Login ke Moodle terlebih dahulu, lalu dari console browser atau Playwright:

```javascript
async function updateSection(sectionId, newHtml) {
  const getResp = await fetch(`/course/editsection.php?id=${sectionId}&sr`, {credentials:'include'});
  const html = await getResp.text();
  const parser = new DOMParser();
  const doc = parser.parseFromString(html, 'text/html');
  const form = doc.querySelector('form[action*="editsection"]');
  const fd = new FormData(form);
  fd.set('summary_editor[text]', newHtml);
  const params = new URLSearchParams(fd);
  const postResp = await fetch('/course/editsection.php', {
    method:'POST', credentials:'include',
    headers:{'Content-Type':'application/x-www-form-urlencoded'},
    body: params.toString()
  });
  return postResp.ok ? 'OK' : 'FAIL ' + postResp.status;
}
```

### Update iframe ke subfolder spesifik
Ketika punya subfolder ID (misal `SUBFOLDER_ID` untuk pertemuan 3 CV), update section 135626:

```javascript
updateSection(135626, existingContent + `
<iframe src="https://drive.google.com/embeddedfolderview?id=SUBFOLDER_ID#list" 
  width="100%" height="350" frameborder="0" style="border:1px solid #dadce0; border-radius:4px;">
</iframe>`);
```

### Cara dapat subfolder ID
1. Buka Google Drive → masuk ke folder pertemuan yang diinginkan
2. Lihat URL: `https://drive.google.com/drive/folders/FOLDER_ID_ADA_DI_SINI`
3. Salin ID tersebut
